# amd-ph-core/.github

Organization-level files and shared assets for the
[amd-ph-core](https://github.com/amd-ph-core) namespace, maintained by CDC's Office of
Advanced Molecular Detection (OAMD).

## Contents

| Path | Purpose |
| --- | --- |
| `profile/amd_logo.png` | AMD Platform logo, light-mode variant |
| `profile/amd_logo_dark.png` | AMD Platform logo, dark-mode variant |
| `standards/` | `ph-core` conformance checklists, one CSV per tier |

These files are referenced by URL from READMEs across the namespace, which is why this
repository is public.

## Standards checklists

`standards/` holds the `v1.0.0` conformance checklist, split by tier. Each row is one
criterion, with `Compliant (Yes-1/No-0)` and `Notes` columns left blank so a file can be
used directly as a review worksheet.

| Tier | File | Items |
| --- | --- | --- |

| 3 | [`...tier3-ph-core-recommendations.csv`](standards/Workflow-Checklist-v1.0.0-tier3-ph-core-recommendations.csv) | 107 |
